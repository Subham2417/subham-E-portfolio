# Subham E — Recruiter Portfolio

Multi-page static portfolio built from the supplied resume and profile photo.

Pages:
- Home
- About
- Experience
- Skills
- Contact

Features:
- Responsive design
- Multicolour reactor-inspired visual system
- Profile photo used across the portfolio
- Detailed experience and skills from the supplied resume
- Resume PDF included
- Cinematic arc-reactor sweep transition when navigating between portfolio pages
- Mobile navigation
- Scroll reveal animations
- Copy-email interaction

The visual direction is inspired by the energy, metallic feel and red/gold/cyan palette associated with a superhero tech aesthetic, without using Marvel/Iron Man logos or copyrighted artwork.

Open `index.html` in a browser to view the site.
